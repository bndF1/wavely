# EGM Drift Report: 2026-11-12

Scope: the 50 `EGM.md` contracts generated by `egm-bootstrap`. Each contract was checked against the current source on `main` (4f46657).

## Triage summary

**Possible code bugs.** The drift review found behaviour in the source that looks unintended. Filed as GitHub issues #381–#386 (item 7 not filed).

1. [#381] `src/app/features/discover/discover.page.ts`: `distinctUntilChanged` on `search$` swallows `retrySearch()`. It also swallows the re-search that should run after a country change.
2. [#382] `src/app/features/radio/radio.page.ts`: clearing the search or changing country does not cancel a pending or in-flight search. Late search results can overwrite the country station list.
3. [#383] `src/app/features/publisher/publisher.page.ts`: a `paramMap` change does not reset `artistId` or `publisherName`. As a result, `retry()` can refetch the previous publisher.
4. [#384] `src/app/app.routes.server.e2e.ts`: there is no `settings` entry, so the route falls through to Prerender in e2e builds.
5. [#385] `e2e/src/page-objects/pages.ts`: `LoginPage` waits for `wavely-login` and the text "sign in with google", and has email and password inputs. None of these exist (the app uses `app-login` and "Continue with Google"). The class is dead code.
6. [#386] `src/app/features/home/home.page.ts`: `hasMoreFeed` and `hiddenFeedCount` count episodes that are hidden by `FEED_MAX_AGE_DAYS`.
7. `src/app/core/services/subscription-sync.service.ts` and `radio-favorites-sync.service.ts`: `loadFromFirestore` has no guard for an empty `uid`.

**Dead or unused code.** `BrowsePage` is not routed. `NxWelcome` is not referenced. `firebaseConfig` is not imported. The `PlaybackProgress` and `Subscription` models are unused. `src/ngsw-config.json` duplicates the root file. No `@capacitor/*` plugin is imported from `src`. The Firestore rules for `queue`, `tokens`, `podcasts` and `episodes` have no client code that uses them.

**Contract corrections (applied 2026-11-12).** The inaccurate claims below have been corrected in the EGM.md files, and the known bugs are linked to #381–#386. Purely cosmetic omissions were deliberately left out: template CSS classes, `defaultHref` values, hard-coded labels and exact timeouts. Contracts cover the interface, invariants and side effects, not every line of a template.

## EGM.md

- The global invariant "All I/O goes through `src/app/core`" is false in two places:
  - `store/layout/layout.store.ts` reads and writes `localStorage` (`wavely-sidebar-collapsed`) directly.
  - `app.ts:App` writes to `users/{uid}/subscriptions/__e2e_probe` in emulator builds, outside the `*-sync` services.
- `firestore.rules` lists `queue`, `tokens`, `podcasts` and `episodes`, but no client code uses them. The contract does not mark these rules as reserved or unused.
- "Credentials enter ... via `import.meta.env`" is misleading. `generate-env.mjs` writes literal values into the environment files. The only reader of `import.meta.env` is `firebaseConfig`, which nothing imports.
- `@capacitor/*` plugins (including push notifications) are dependencies and are configured in `capacitor.config.ts`, but no `src` file imports them. The contract does not say this.
- Analytics is enabled in every non-emulator build with no configuration check. Only Sentry depends on configuration.
- These are not documented:
  - `capacitor.config.ts` switches to `CAP_ENV=local` with a `server.url` on localhost:4200.
  - `cap:build` copies `index.csr.html` to `index.html`.
  - `firebase.json` sets a 1-year `Cache-Control` header.
  - `project.json` has a `serve-static` target.
  - The `staging` build has no service worker.
- `src/ngsw-config.json` duplicates the root `ngsw-config.json`, and only the root file is referenced.
